# Keyboard Stabilizer guide

The operating instructions are in the [User guide](docs/USER_GUIDE.md).

Start with D selected, **Smooth hold (start here)** selected, and live output off. The default release grace is `12 ms`. Press **F8** to stop an armed or active session.

See [Build and test](docs/BUILDING.md) for build commands. See [Compatibility and privacy](docs/COMPATIBILITY_AND_PRIVACY.md) for input limits and Valorant status.
